# 소문난 판결소 V4 UX 방향

V3의 긴 세로형 소개·입력·다음 버튼 구조를 폐기한다.

## 핵심 구조
- 사건 접수 후 전체 화면 수사본부로 전환
- 중앙 사건보드에서 현장, 잠복차량, 감식실, 심문실, 브리핑실, 법정을 직접 선택
- 문서 열람이 아니라 사용자의 선택과 조작으로 단계가 진행
- 선택 결과가 판결 점수와 후일담에 반영

## 필수 상호작용
1. 잠복 위장 방식 선택
2. 감식할 증거 선택
3. 피의자 질문과 모순 지적
4. 법정에서 제출할 핵심 증거 선택
5. 최종 형벌 조합

## 화면 원칙
- 긴 랜딩 페이지 금지
- 데스크톱: 좌측 사건 상태, 중앙 사건보드, 우측 현장 기록
- 모바일: 하단 장소 독과 전체 화면 임무 카드
- 단순 다음 버튼 중심 진행 금지
- 각 장소에 완료 상태, 새 단서, 미확인 알림 표시
