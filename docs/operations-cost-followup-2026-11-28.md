# 운영 비용 후속 점검 — 2026-11-28
- 배포 대상은 dist-public이며 public/flix 및 flix-review/admin에서 빌드한다. 이전 서비스의 코드나 브랜치, 운영 데이터를 일괄 삭제하지 않는다.
- 10분 주기 조회 요청은 상태·요청 정보만 필드 마스크로 가져온다. 완료 결과(최대 600KB)를 반복 다운로드하지 않는다. 읽기 문서 수 자체는 동일하며 실제 전송량 절감은 결과 크기 및 실행 횟수에 따라 달라진다. 관리자 결과 조회 방식과 요청 권한 검사는 유지한다.
- 초기 카탈로그 등록 마커가 있으면 트랜잭션에서 카탈로그를 읽지 않는다. 반복 배포마다 문서 읽기 1회와 전체 카탈로그 전송을 줄인다. 최초 적용과 동시 실행 시 트랜잭션으로 기존 보호를 유지한다.
- 자동 수집 10분 확인/6시간 정기 검사, 연령 제한 재검증, SEO 갱신, 시청 통계 및 공개 반영 기능을 유지한다. 비용 절감을 이유로 안전 검사를 제거하지 않는다.
- 운영 콘솔에서 확인 필요: Billing 보고서 프로젝트 sosoking-481e6/SKU별 일일 비용, Firestore 읽기·쓰기·네트워크 전송량, Secret Manager 활성 버전과 복제 정책, 기존 Functions/Cloud Run 서비스와 트리거, Storage 파일 및 백업. GitHub만으로 실사용/청구를 확인하거나 삭제할 수 없으므로 운영 리소스는 변경하지 않는다.
- 운영 계정 Google 로그인/설치형 앱/TV 실제 검증은 별도 필요. 이전 PR은 현재 배포 대상과 대조한 뒤 정리한다.

- 후속 CI 수정: 실제 worker를 실행하는 in-memory Admin SDK에 getAll 필드 마스크 구현을 추가하고 완료 결과 제외 및 대기 요청 오류 처리 회귀 검증을 추가했다. 최신 main의 조회 안내와 관리자 기능은 유지한다.
