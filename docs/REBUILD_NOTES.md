## 정리 원칙

1. 새 서비스 기획이 확정되기 전에는 기존 UI나 기능을 일부 재사용하지 않습니다.
2. 인증·데이터·보안 구조도 새 기획에 맞춰 다시 결정합니다.
3. 기존 Firestore와 Storage 규칙은 현재 운영 데이터 보호를 위해 참고용으로 유지합니다.
4. 기존 배포된 Cloud Functions는 별도 점검 후 유지·중지·삭제를 결정합니다.
5. 새 자동 배포 Workflow는 서비스 구조와 테스트가 확정된 후 새로 작성합니다.
