# 소문난 판결소 수사본부 V3

## 목표

사소한 일을 법정 문서 몇 장으로 끝내지 않고, 사용자가 작은 코미디 수사극 한 편을 읽고 체험하도록 확장합니다.

## 경험 흐름

1. 사건 접수
2. 초동 출동
3. 잠복 수사
4. 과잉 감식 및 압수수색
5. 피의자 신문
6. 공개 브리핑과 법정 공방
7. 최종 판결과 후속 사건

## 코미디 원칙

- 사건은 하찮고 절차는 국가 비상사태처럼 엄숙합니다.
- 실제 기관은 사용하지 않고 국가과잉수사연구소, 생활질서 특수본 같은 가상 패러디 기관만 사용합니다.
- 잠복 위치, 위장 방식, 투입 인력, 감식 방법, 압수 물품, 기자 문답처럼 작은 디테일마다 새로운 웃음을 배치합니다.
- 한 번에 긴 글을 보여주지 않고 작전일지, 감식서, 증거봉투, 신문기록, 브리핑 보드로 나눕니다.
- 사람을 조롱하지 않고 사소한 행동과 과잉 절차를 웃음의 대상으로 삼습니다.

## 미리보기 안전

- 운영 Hosting은 변경하지 않습니다.
- 미리보기 API는 별도 `generateCourtCaseV3` 함수를 사용합니다.
- 기존 운영 API `generateCourtCase`는 미리보기 평가 중 교체하지 않습니다.
- 대표 사건 20개에서 모든 상세 필드와 중복 여부를 검사합니다.
