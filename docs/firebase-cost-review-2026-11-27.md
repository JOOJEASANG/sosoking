| 자동 수집 대기 | 10분마다 큰 보고서·카탈로그·설정도 읽음 | 대기 중 작은 요청·상태 문서 4개만 읽고 쓰기는 생략 |

한 시간 계속 시청하는 경우 **정기 통계 저장 주기는 60회에서 12회로 80% 감소**한다. 접속 시작·탭 이탈 저장, 트랜잭션 재시도, 보안 규칙의 종속 문서 조회는 별도다. 이 비율은 전체 청구 금액의 절감률이 아니다. 관리자 공개 반영 때는 작은 수집 신호 문서를 1회 추가 저장해 변경을 감지한다.

자동 수집 요청 확인은 약 10분, 정기 전체 수집은 6시간, 검색 하루 상한은 80회로 유지한다. API 오류의 재시도 대기와 수동 재수집도 유지한다. 추가 유료 서버·Cloud Functions·Secret Manager 리소스를 만들지 않는다.

## 수정한 오류

- 3.5초 이후 도착한 공개 목록이 무시되던 문제: 서버 응답을 끝까지 반영한다. 느린 정적 파일 응답이 최신 목록을 덮어쓰는 경우도 방지한다.
- 임시 목록 표시 중 기록 정리: 최신 목록에만 있는 찜·시청 기록을 임시 정적 목록 때문에 지우지 않는다.
- 공개 목록 변경 중 시청: 같은 영상은 재생을 유지하고, 숨김·삭제된 작품 또는 회차는 재생을 종료한다.
- 관리자의 즉시 등록 중 편집: 등록이 끝나기 전 작업 영역을 잠그고 성공·실패 모두 해제해 대기 중 입력한 내용이 초기화되는 일을 막는다.
- 작은 PC 창에서 자동 극장 모드가 켜지던 문제: 터치 기기의 가로 화면에만 자동 적용한다.
- 자동 수집 실패 은폐: API 키 누락, 부분 수집 실패, 충돌, 요청 처리 실패를 실행 실패로 표시한다. 기존 실패 기록을 읽기만 한 대기 실행은 다시 실패 처리하지 않는다.
- 5분 통계 저장에 맞춰 최초 생성·일자 변경·누적량 규칙을 함께 수정하고 실제 경과 시간을 초과하는 증가를 거부한다.
- Google 회원 로그인에 관한 개인정보 안내를 보완한다.

## 의존성 및 배포

- 설치 잠금 파일과 `npm ci`로 개발·CI·자동 수집의 의존성을 일치시킨다.
- `@grpc/grpc-js`는 1.14.5, `uuid`는 CommonJS 지원 패치 버전 11.1.1로 고정한다. 사용 중인 Google SDK의 UUID 호출은 `v4()`이며 초기화 호환성을 확인했다.
- 참고: [gRPC 보안 수정](https://github.com/advisories/GHSA-m9gg-hp2v-232j), [gRPC 후속 보안 수정](https://github.com/advisories/GHSA-f596-whhp-79r4), [UUID 보안 수정](https://github.com/advisories/GHSA-w5hq-g745-h8pq).
- 새 관리자 화면은 공개 목록과 수집 신호를 함께 저장한다. 따라서 배포 순서를 **검사 → 기존 규칙 일치 확인 및 규칙 적용 → Hosting 배포**로 맞췄다. 기존 클라이언트의 1분 통계 저장은 새 규칙에서도 허용된다.
- 규칙 적용은 알려진 이전 규칙과 정확히 일치할 때만 허용하며 다른 서비스의 규칙 변경은 거부한다.

## 검증 방법

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run test:rules
npm audit
```

단위 검사는 캐시 만료·동시 요청·새 공개 반영과의 경합, 통계 저장 및 동의 철회, 자정 경계, 관리자 캐시 격리, 자동 수집 조회 수와 실패 처리를 포함한다. 브라우저 검사는 목록 지연·임시 목록 경합·재생 유지·극장 모드·수동 새로고침·즉시 등록 잠금을 포함한다. Firestore 규칙은 `demo-sosoking` 에뮬레이터에서 검사한다. 영상 재생·로그인·수집 응답은 필요한 부분을 모의 처리하며 실제 YouTube 전체 영상 재생 성공을 보장하는 검사는 아니다.

## 운영에서 별도로 확인할 항목

- 실제 비용은 배포 후 Firebase/Google Cloud 사용량으로 비교해야 한다. 코드만으로 Secret Manager의 활성 버전·복제본, 과거에 만든 Cloud Run/Functions, 저장된 파일의 과금을 확인하거나 정리하지 않았다.
- 개인정보 문의처의 운영자 정보는 실제 연락처로 채워야 한다.
- YouTube 연동용 공개 API 키·OAuth 클라이언트 ID, 푸시 알림 설정이 비어 있으면 해당 선택 기능은 사용할 수 없다. 임의의 값을 만들거나 기능을 활성화하지 않았다.
- 캐시 때문에 다른 기기에서 바뀐 목록은 다음 조회에서 최대 5분 동안 이전 내용이 보일 수 있다. 사용자는 ‘최신 목록 확인’으로 즉시 확인할 수 있고, 같은 브라우저의 관리자 공개 반영은 다른 열린 탭에 전달한다.
- 통계는 동의한 브라우저의 추정치다. 브라우저를 즉시 종료하거나 오프라인 상태가 되면 마지막 저장 전 기록 일부가 누락될 수 있다.
