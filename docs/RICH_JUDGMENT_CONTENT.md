# 판결 콘텐츠 보강 기준

판결 결과가 사건에 따라 한두 문장으로 끝나는 문제를 방지하기 위해 다음 기준을 적용합니다.

- 접수 기록, 조사 기록, 원고·피고 변론에 최소 분량 적용
- 사건 맞춤형 증거물 3개 생성
- 재판부 집중신문 3개 생성
- 핵심 판단 3개 생성
- 판사 성향이 반영된 재판부 특별 논평 생성
- 최종 판결문을 6~10문장으로 생성
- 선고 후 후일담 생성
- 기준에 미달한 AI 응답은 한 번 자동 재작성
- AI 생성에 실패해도 짧은 공통 문장이 아닌 장문 예비 판결문 사용

결과 문서에는 `contentVersion: 2`와 `generationMode`를 저장해 생성 품질 상태를 구분합니다.
