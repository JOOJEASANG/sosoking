# V3 UX 및 디테일 검수표

## 첫 화면
- 양쪽 `소` 인장이 즉시 보이는가
- 작전본부와 사건기록의 이중 분위기가 전달되는가
- 입력 방법과 수사 확대 수준을 10초 안에 이해할 수 있는가

## 수사 단계
- 각 단계마다 이전 단계와 다른 시각 형식이 있는가
- 초동 출동에 시간·부서·행동·현장 메모가 있는가
- 잠복 수사에 장소·시간·위장·관찰·예상 밖 성과가 있는가
- 감식에 방법·결과·쓸데없는 결론이 있는가
- 압수수색에 가상 영장·대상·압수품·요원 메모가 있는가
- 증거봉투를 눌러 해석을 확인할 수 있는가
- 심문 질문 3개가 서로 다른 웃음을 주는가
- 브리핑의 기자 질문과 공식 답변이 서로 맞물리는가
- 검사·변호인 주장이 모두 조금씩 설득력 있는가
- 판결 3개와 후일담 3개가 확실히 다른가

## 모바일
- 진행 단계가 가로 스크롤로 잘리지 않는가
- 하단 진행 버튼이 안전영역을 침범하지 않는가
- 모든 선택 버튼이 한 손으로 누르기 충분한가
- 긴 사건명과 감식 결과가 화면 밖으로 넘치지 않는가

## 공유
- 사용자 원문과 개인정보가 결과 이미지에 포함되지 않는가
- 사건명·판결·형벌·후일담·재판관 성향이 읽히는가
