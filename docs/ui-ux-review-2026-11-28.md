| 관리자 입력 | 검색된 작품과 편집 중 작품의 관계가 불명확 | 검색 결과 수와 선택 유지 안내, 필수 표시, 오류 위치 표시 |
| 백업 | 파일 불러오기가 미공개 초안을 바로 교체 | 초안 교체 확인, 취소 시 보존, 백업 내보내기 우선 배치 |
| 대시보드·후보 검토 | 긴 기술 안내가 핵심 작업을 밀어냄 | 작업 바로가기와 접을 수 있는 운영 안내 |
| 로컬 미리보기 | 서버가 지정 포트를 무시하고 하위 경로 index를 처리하지 않음 | host/port 옵션, 디렉터리 index와 이미지 MIME 지원 |

## 비용·데이터 보존

- 검색, 메뉴 전환, 회차 접기, 추천 전환 제어는 브라우저 내 동작이다. 새 Firestore 조회·리스너·백그라운드 작업을 추가하지 않았다.
- 기존 목록 5분/추천 1시간 캐시, 통계 5분 전송, 관리자 집계 15분 재사용, 수집 제한을 유지한다.
- Firestore 보안 규칙, 인증 권한, 작품 원본 데이터, 자동 공개 정책은 변경하지 않는다.
- 백업은 작품 저장을 마친 목록을 대상으로 한다. 공개 전 초안은 현재 화면 메모리에 보관되므로 새로고침 전 공개 반영 또는 백업해야 한다. 기존 페이지 이탈 경고는 유지한다.

## 검증

- 로컬 `npm test`: 107개 통과. `npm run build` 및 `git diff --check` 통과.
- 실제 브라우저에서 PC 헤더/검색/관리자 편집·저장, 390px 관리자 7개 메뉴, 320px 후보 검토·시청 검색 배치를 확인했다.
- 관리자 화면은 테스트 데이터와 실제 편집 모듈로 점검했다. 운영 데이터에 테스트 작품을 저장하지 않았다.
- 기존 CI 브라우저 검사에 헤더 단일 행, 검색 복구, 추천 일시정지 유지, 데스크톱 작업 바, 회차 접기/필수 입력 펼침, 백업 취소 시 초안 보존, 모바일 메뉴 겹침 회귀 검사를 추가했다.
- 전체 브라우저 시나리오와 Firestore 에뮬레이터 권한 검사는 PR의 Test & Deploy 작업에서 확인한다.
