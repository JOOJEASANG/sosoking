# 관리자 후보 정리 및 작품 삭제 — 2026-11-28
- 수집 후보 개별/그룹 제외를 명확히 표시하고, 검색 결과에 포함된 후보는 즉시 등록 가능 여부에 상관없이 별도로 선택해 일괄 제외한다.
- 작품 관리의 작품 삭제 또는 여러 개 삭제는 확인 후 카탈로그와 제외 영상 ID를 동일 트랜잭션에서 저장한다. 최신 버전 충돌, 미공개 편집, 제외 목록 한도 초과 시 중단한다. 전체 삭제는 추가 확인한다.
- 기존 편집 후 공개 반영에서 빠진 원본 영상 ID도 같은 방식으로 제외한다. 다른 회차에 동일 원본이 남아 있으면 제외하지 않는다.
- 제외 목록의 기존 500개 상한과 관리 권한, 자동 수집 간격, 기존 사용자 기록은 유지한다. 제외 해제하면 자동 수집 대상이 될 수 있다. 다른 ID의 재업로드까지 차단하지는 않는다.
- YouTube 원본을 삭제하지 않으며 배포 후 실제 관리자 계정으로 테스트 필요. 브라우저 회귀는 모의 저장 콜백 사용.
