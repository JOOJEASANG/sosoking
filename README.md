# 소소킹 플레이

링크 하나로 모여 2~8명이 바로 즐기는 모바일 파티게임 웹앱입니다.

## 게임

- 소소킹 월드: 24칸 보드, 영역과 통행료, 미니게임 이벤트
- 금고런: 남과 겹치지 않는 금고를 고르는 눈치게임
- 욕심계단: 위험을 감수하고 더 오를지 결정하는 배짱게임
- 딱걸렸어: 가장 작은 단독 숫자를 노리는 심리전
- 초성 폭탄: 남과 겹치지 않는 초성 단어 게임

## 개발

```bash
npm ci
npm run check
```

Firestore 규칙 검증은 Firebase CLI와 Java가 필요합니다.

```bash
npm test
```
