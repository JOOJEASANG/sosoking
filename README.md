# 소소킹 LIVE

필요한 프로그램을 골라서 행사방을 만들고, QR코드 하나로 참가자가 입장하는 웹 행사 플랫폼입니다.

## 포함된 프로그램

1. 행운권 추첨: 서버 무작위 추첨, 중복 당첨 제외
2. 실시간 투표: 1인 1회 투표, 시작/마감, 득표 확인
3. 룰렛: 상품 및 항목 선택, 추첨 기록
4. 점수판: 팀/개인 점수 관리
5. 랜덤 팀 나누기: 참가자 균등 배분
6. 행사 타이머: 시간 설정, 시작/중지/초기화
7. 대진표: 2~32팀 토너먼트, 부전승, 승리팀 자동 진출

OX 퀴즈는 제외했습니다.

## 운영 방식

- 행사명과 사용할 프로그램을 선택해 행사방 생성
- 공용 QR코드를 참가자에게 공유 (진행자 비밀키 노출 없음)
- 참가자 닉네임으로 입장
- 진행자: 필요한 프로그램 활성화 및 결과 발표
- 참가자: 현재 진행 중인 프로그램만 참여
- Firestore 및 Cloud Functions 서버에서 추첨/투표 결과 기록 및 참가자에게 공유
- 약 6초 간격 갱신: 완전한 push 실시간은 아니므로 수 초 지연 가능
- 행사 없이 프로그램을 바로 사용하는 로컬 모드 제공

## 기술 구성

Vite/Vanilla JS, qrcode, Firebase Functions v2 (Node 22), Firebase Admin SDK, Firestore, Firebase Hosting.

설치: npm install
웹 빌드: npm run build
기본 검증: npm run check && node tools/check-site.mjs

GitHub Actions는 sosokingEventApi 함수만 지정하여 배포한 뒤 Hosting을 배포합니다. 기존 Firebase Functions와 Firestore 규칙을 건드리지 않습니다.

## 첫 버전 제한 사항

- 행사당 최대 200명, 생성 후 7일간 이용
- 행사 생성 IP당 하루 5회까지
- 관리자 비밀키는 행사 생성 기기의 브라우저 로컬 저장소에 보관; 저장소를 지우면 관리 권한을 잃을 수 있음
- 본인 인증 없는 닉네임 입장: 여러 기기를 이용한 중복 참여를 완벽히 차단할 수 없음
- 대진표는 토너먼트 방식 우선 구현. 리그/조별리그 확장 예정
- 고빈도 트래픽이 발생하면 Firebase 사용 요금 발생 가능
- 기존 회원/Firestore 자료/이전 Functions는 삭제하지 않음
- 기존 소스 백업: backup/pre-clean-slate-20261023


## 2026-10-24: 로고 / 온라인 모임 / 바로 쓰는 미니게임

- 브라우저 favicon 및 홈 화면 앱 아이콘을 새로운 소소킹 브랜드 마크로 교체 (SVG 원본, 자동 PNG 192/512 빌드)
- 행사 참여방식: 현장 / 온라인 / 혼합 모드
- 온라인 모임 초대 링크 복사·공유, 화상회의 화면공유용 읽기 전용 발표 화면 제공
- 행사 생성 이후에도 7가지 프로그램을 추가하거나 제외하는 관리자 설정
- 홈 메인에 즉시 실행 가능한 룰렛 / 추첨 / 대진표 / 팀 나누기 배치
- 행사 없이 사용하는 도구에는 샘플 1클릭 시작 기능 제공 (현장용과 서버 공유 기능 구분)
- QR 입장은 기존 방식 유지. 온라인 링크로 접속해도 동일한 행사 참여 페이지에 들어옵니다.


## 프로그램별 독립 페이지 (2026-10-24)

- 행사 관리실은 QR 공유, 참가자 관리, 프로그램 목록을 담당하며 프로그램을 페이지 안에 표시하지 않습니다.
- 행사방에서 각 프로그램을 선택하면 새 탭에 `/#/manage/{행사ID}/tool/{프로그램ID}`가 열립니다. 첫 진입 시 참가자 화면에도 해당 프로그램을 활성화합니다.
- 행사 없이 쓰는 도구도 `/#/tool/{프로그램ID}` 전용 페이지가 새 탭으로 열립니다.
- 각 전용 페이지에는 해당 도구의 설정·실행·기록만 표시하며, 전체화면·돌아가기·행사 발표 화면 기능을 제공합니다.
- 새 탭에서 진행해도 참가자 정보와 결과는 기존 행사방에 연결됩니다. 한 행사에서 참가자에게 표시되는 활성 프로그램은 한 번에 하나입니다.


## 2026-10-24 프로그램별 세부 기능

- 각 프로그램에 한눈에 보는 3단계 사용 가이드와 안내 추가
- 추첨: 한 번에 1·2·3·5·10명 선정, 이미 당첨된 참가자 자동 제외, 최신 추첨 결과 및 전체 당첨 기록 분리
- 서버 추첨은 암호학적으로 안전한 난수 생성기를 사용하고, 개별 브라우저 추첨도 브라우저 crypto 난수 사용
- 룰렛: 개별 항목을 실제 원형 구간으로 표시, 회전 애니메이션, 뽑기 결과 기록
- 점수판: +1/-1/+5/-5 점수 조작
- 타이머: 30초·1분·3분·5분·10분 빠른 설정, 종료 시 배경 색상 변경
- 모든 전용 페이지에 결과 CSV 저장, 인쇄 기능 추가. CSV는 엑셀 수식 실행을 유도하는 입력을 이스케이프합니다.
- 참가자 QR 링크와 온라인 발표 화면, 독립 프로그램 페이지 동작은 기존 구조 유지

Vite 멀티페이지 빌드로 각 URL에 고유 title, description, canonical, OG, 구조화 데이터, 서버에서 읽을 수 있는 기본 안내문을 제공합니다. 자바스크립트를 실행하면 같은 페이지에 인터랙티브 도구가 표시됩니다.

SEO 페이지 설명: tools/seo-programs.json
정적 페이지 자동 생성: npm run prepare:seo
정적 공개 sitemap: https://sosoking.co.kr/sitemap.xml
크롤러 설정: https://sosoking.co.kr/robots.txt
이전 해시 라우트 #/tool/... 는 기존 링크 호환성을 위해 유지합니다.

검색 서비스 등록: 사이트 운영자는 Google Search Console 및 네이버 서치어드바이저에서 sosoking.co.kr 소유 확인을 진행하고 sitemap.xml 을 제출해야 합니다. 이 작업은 현재 GitHub 배포만으로 수행되지 않습니다.
검색 색인/순위는 보장되지 않으며 실제 수집 상황을 각 검색 서비스에서 확인해야 합니다.

디자인은 밝은 배경, 일관된 여백, 간결한 카드, 모바일 가독성 중심으로 정리했습니다.
