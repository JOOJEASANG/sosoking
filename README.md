# RIFT GUARD · SOSOKING DEFENSE

**[게임 플레이](https://sosoking-481e6.web.app/)**

광고나 결제 없이 즐기는 오리지널 3D 웹 타워 디펜스. PC와 모바일 브라우저에서 플레이할 수 있습니다.

## 2.0 비주얼 업그레이드
- Three.js WebGL 3D 전장, 실시간 그림자와 조명, 입체형 포탑/적 유닛/코어/차원문, 입체적 타일 및 산업 구조물.
- 클릭/탭은 3D 레이캐스팅으로 바닥을 판정해 배치 가능. 3D를 지원하지 않는 환경에서는 기존 2D 화면으로 자동 전환.
- esbuild로 Three.js를 단일 브라우저 모듈에 번들링하므로 Firebase에서 외부 CDN 호출 없이 작동.


## 게임 플레이
- 북쪽과 남쪽 2개의 차원문에서 동시에 적군이 침공합니다. 중앙 코어를 지키세요.
- 펄스 캐논(고속 단일), 서리 방사기(광역 둔화), 레일 스나이퍼(관통), 아크 코일(연쇄 공격) 4종 방어 시설.
- 포탑을 선택하여 레벨 4까지 강화하거나 철거해 자금을 회수할 수 있습니다. 시설을 재배치할 수도 있습니다.
- **공명 연계**: 서로 다른 종류의 포탑을 근처에 배치하면 연결당 공격력 +13%, 최대 +39% 보너스가 발생합니다.
- 매 웨이브 종료 시 무작위 프로토콜 3개 중 하나를 선택합니다. 공격력, 공속, 사거리, 경제, 수리 등 지속적인 강화가 가능합니다.
- 5웨이브마다 보스가 등장합니다. 적을 공격하고 처치해 오버드라이브를 충전하면 8초간 적의 속도가 감소하고 포탑 발사 속도가 증가합니다.
- 정찰 / 작전 / 극한 난이도, 최고 기록 저장 (기기 브라우저 localStorage).
- 웨이브 종료 후 체크포인트가 자동 저장되어 새로고침 이후에도 작전을 이어 할 수 있습니다.

## 조작
1~4 포탑 선택 · 전장 클릭/탭으로 건설 · 설치된 포탑 클릭으로 강화/철거 · Enter 웨이브 시작 · Space 오버드라이브 · P 일시정지 · F 2배속 · ESC 선택 해제.

## 개발
Node.js 20 이상 필요. `npm install`으로 Three.js 및 esbuild를 설치해야 합니다.

    npm install
    npm run dev
    npm run check
    npm run build

브라우저에서 localhost:3000 으로 접속. 정적 배포용 파일은 dist-public/ 에 생성됩니다.

## 배포
main 브랜치에 푸시하면 GitHub Actions에서 Node 테스트 및 빌드 후 Firebase Hosting (sosoking-481e6)에 배포합니다. 기존 저장소를 새 게임으로 완전히 교체하되 Firebase 프로젝트 식별자와 GitHub Actions 배포 비밀키 이름은 유지합니다.

## 프로젝트 구성
- public/js/rules.js: 게임 데이터, 경로, 웨이브 생성 및 강화 규칙
- public/js/game.js: 게임 엔진, 입력, 애니메이션, 오디오, UI
- public/index.html, public/style.css: 반응형 화면
- tests/: 게임 규칙 회귀 테스트
- scripts/: 로컬 웹 서버, 정적 빌드

본 프로젝트는 싱글플레이 게임입니다. 로그인, 구매, 서버, 데이터베이스가 필요하지 않습니다.
