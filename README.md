# SKYBREAK · 스카이브레이크

[게임 플레이](https://sosoking-481e6.web.app/)

세 대의 우주 전투기 중 한 대로 외곽 궤도, 잔해 지대, 코어 방어선을 돌파하는 1인용 아케이드 슈팅게임입니다. 전장은 깊이 좌표에 따라 원근 투영되며, 플레이어 기체에는 기울기에 반응하는 고해상도 외형을, 적 편대와 보스에는 실시간 3차원 메시를 사용합니다. 모든 게임 자산을 함께 배포하며 기체 설정과 비행 기록은 브라우저에 저장합니다.

| 기체 | 무장 | 보호막 |
| --- | --- | ---: |
| 팔콘 | 트윈 펄스포 | 100 |
| 레이스 | 속사 레이저 | 78 |
| 바스티온 | 삼연장 산탄포 | 145 |

방향키·WASD 또는 화면 드래그로 이동합니다. 기본 무장은 자동 발사됩니다. Space 또는 화면 버튼으로 충격파를 사용하고, Esc 또는 P로 일시정지할 수 있습니다. 난이도에 따라 편대 규모, 적의 사격 빈도, 피격 피해량과 점수 배율이 달라집니다.

## 실행

Node.js 22 이상에서 추가 패키지 설치 없이 실행할 수 있습니다.

```sh
npm run dev
npm run check
npm run build
```

기본 로컬 주소는 http://127.0.0.1:5173 입니다. 빌드 결과는 `dist/`에 생성되며 `main`의 변경 사항은 기존 Firebase Hosting 프로젝트에 배포합니다.
