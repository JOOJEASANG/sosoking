# 소문난 판결소 MVP

아주 사소하고 유치한 일상을 필요 이상으로 수사하고, 과도하게 진지한 법정 공방과 판결로 확대하는 코미디 서비스입니다.

로고는 첫 글자와 마지막 글자인 두 개의 **소**를 동일한 도장 형태로 강조합니다.

> **소**문난 판결**소**
>
> 별일 아니지만, 일단 재판부터 열겠습니다.

## 핵심 경험

1. 사용자가 오늘 있었던 사소한 일을 한 줄로 입력합니다.
2. 사건이 거창한 사건명과 혐의로 확대됩니다.
3. 쓸데없이 정밀한 증거를 조사합니다.
4. 피고를 심문하고 말도 안 되는 해명을 듣습니다.
5. 검사와 변호인이 지나치게 진지하게 공방합니다.
6. 사용자가 황당하지만 상황에 맞는 판결을 선택합니다.
7. 판결 집행 직후 새로운 문제가 생기는 후일담으로 끝납니다.

## 현재 시연판

`public/`에는 서버나 유료 AI 연결 없이 핵심 재미를 확인할 수 있는 프런트엔드 시연판이 있습니다.

- 사건 입력 및 글자 수 제한
- 사건 확대 수준 3단계
- 음식·지각·전자기기·메신저·일반 사건 분류
- 사건 접수 → 수사 → 심문 → 공방 → 판결 진행
- 선택형 심문과 판결
- 판결 집행 후 반전 후일담
- 심각한 범죄 소재 및 기초 개인정보 입력 차단
- 모바일 반응형 화면

현재 사건 생성은 시연용 규칙 기반 템플릿입니다. 핵심 흐름과 코미디 품질을 검증한 뒤 생성 부분만 실제 AI API로 교체합니다.
