# 소문난 판결소 MVP

아주 사소하고 유치한 일상을 필요 이상으로 수사하고, 과도하게 진지한 법정 공방과 판결로 확대하는 AI 코미디 서비스입니다.

로고는 첫 글자와 마지막 글자인 두 개의 **소**를 동일한 붉은 인장 형태로 강조합니다.

> **소**문난 판결**소**
>
> 별일 아니지만, 일단 재판부터 열겠습니다.

## 핵심 경험

1. 사용자가 오늘 있었던 사소한 일을 한 줄로 입력합니다.
2. AI 재판부가 거창한 사건명과 허구의 혐의를 작성합니다.
3. 쓸데없이 정밀한 증거 세 개를 조사합니다.
4. 피고를 심문하고 뻔뻔한 해명과 정색 반박을 확인합니다.
5. 검사와 변호인이 사소한 문제를 국가적 쟁점처럼 다룹니다.
6. 사용자가 세 가지 판결 중 하나를 선택합니다.
7. 판결 집행 직후 더 유치한 문제가 생기는 후일담으로 끝납니다.

## 현재 구현

### 프런트엔드

- 사건 입력과 120자 제한
- 정식 수사·특별 수사·국가급 대응 선택
- 사건 → 수사 → 심문 → 공방 → 판결 진행
- 선택형 심문과 판결
- AI 생성 중 로딩 상태
- AI 응답 실패 시 예비 판례 자동 전환
- AI 맞춤 재판과 예비 판례 구분 표시
- 심각한 범죄 소재 및 기초 개인정보 입력 차단
- 전용 SVG 아이콘, 판결 도장, 모바일 반응형 디자인

### 서버

- Firebase Functions 2세대 `generateCourtCase`
- 서울 리전 `asia-northeast3`
- OpenAI Responses API와 구조화 JSON 출력 사용
- 사건명·증거 3개·심문 3개·공방·판결 3개·후일담 형식 고정
- OpenAI 응답 저장 비활성화
- API 키를 Google Cloud Secret Manager에서만 사용
- 허용 출처 확인과 기본 요청 횟수 제한
- Hosting `/api/generate-case` 경로를 서버 함수로 연결

## AI 비밀키 설정

API 키를 저장소나 브라우저 코드에 작성하지 않습니다. 배포 환경에서 다음 명령으로 Secret Manager에 등록합니다.

```bash
firebase functions:secrets:set OPENAI_API_KEY
```

그다음 함수 의존성을 설치합니다.

```bash
cd functions
npm install
```

배포가 승인된 뒤에만 다음 명령을 사용합니다.

```bash
firebase deploy --only functions:generateCourtCase,hosting
```
