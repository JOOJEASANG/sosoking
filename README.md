# 소소킹 플레이

링크 하나로 모여 2~8명이 바로 즐기는 모바일 파티게임 웹앱입니다.

## 게임

- 소소킹 DNA: 친구들의 실제 선택 성향을 모아 그 방 전용 보스와 개인별 반대 임무를 만드는 오리지널 게임
- 금고런: 남과 겹치지 않는 금고를 고르는 눈치게임
- 초성 폭탄: 남과 겹치지 않는 초성 단어 게임
- 관심법: 친구의 선택을 사람별로 예측하는 관계 심리게임
- 변명거래소: 황당한 사건의 변명을 만들고 신뢰칩을 거는 창작게임

게임이 끝나면 방장이 원하는 다음 게임을 고를 수 있습니다. 방 코드와 참가자는 유지되고,
모든 참가자가 새 게임 화면으로 자동 이동하며 일반 점수만 새로 시작합니다. 플레이 DNA는
이어져 게임을 거듭할수록 친구별 성향이 더 선명해집니다.

소소킹 DNA의 AI 디렉터는 한 방에서 한 번만 호출합니다. 닉네임과 게임 안에서 만든 성향
수치만 전송하며, 응답이 없거나 Vertex AI가 비활성화되어도 내장 오리지널 보스로 즉시
계속됩니다. 기본 모델은 `gemini-2.5-flash-lite`이며 Firebase 런타임의 서비스 계정 인증을
사용하므로 별도 클라이언트 API 키를 노출하지 않습니다.

실제 AI 문구 생성을 사용하려면 Google Cloud 프로젝트에서 Vertex AI API를 활성화하고,
Functions 런타임 서비스 계정에 Vertex AI 호출 권한을 부여해야 합니다. 호출은 DNA 게임
한 판당 최대 1회, 출력 520토큰, 사용자당 하루 12회로 제한되며 유휴 인스턴스는 0개입니다.
