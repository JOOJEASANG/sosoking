# 물결우체국 · Tidepost

[물결우체국 플레이](https://sosoking-481e6.web.app/)

열여섯 섬을 항해하며 편지를 배달하고 작은 우체국을 세우는 한국어 입체 보드게임입니다. 결제, 광고, 회원가입 없이 같은 우표와 특급권으로 출발합니다.

- **친구와 플레이** — 방을 만들고 초대 링크나 8자리 코드를 나눕니다. 2~4명이 승선하면 방장이 출항합니다. 새로고침 후에도 기존 좌석으로 돌아옵니다.
- **혼자 연습** — 브라우저에서 연습 선장 마루와 같은 규칙으로 8라운드를 플레이합니다.
- **규칙** — 주사위 두 눈 중 하나를 고르거나 특급권으로 합을 사용합니다. 두 라운드마다 진행 방향이 바뀌고, 목적지를 지나면 보상이 지급됩니다. 최종 점수는 별도장 + 남은 우표 3장당 1점입니다. 점수가 같으면 공동 우승입니다.

## 개발

Node 22.13 이상. 런타임 패키지 설치 없이 실행합니다.

    npm run dev
    npm run check
    npm run build
    npm run build:server

개발 서버는 정적 화면과 동일 출처의 방 API를 함께 제공합니다. 로컬 게임방은 SQLite에 저장됩니다. 게임 규칙은 클라이언트와 서버가 공유합니다. 온라인 주사위, 이동, 점수, 차례, 시간 초과는 서버에서 판정합니다. 방 코드와 별도로 기기별 승선 키를 검증하며, 재전송은 같은 행동을 두 번 처리하지 않습니다.

## 배포

- Firebase Hosting은 main의 GitHub Actions에서 정적 화면을 점검·빌드·배포합니다. 배포 전 실제 방 서버에 두 명이 참가해 턴을 교대하고, 배포 후 공개 화면을 확인합니다.
- 방 API는 별도 Sites 배포와 D1 바인딩 DB를 사용합니다. 소스는 server/, public/js/rules.js, drizzle/에 있습니다. 서버나 규칙을 바꾸면 npm run build:server로 워커를 빌드하여 연결된 Sites 프로젝트에 먼저 배포합니다.
- 좌석은 초대 코드와 해당 기기의 승선 정보로 복구합니다. 활동이 끝난 방은 만료되며 공개 방 목록을 제공하지 않습니다.
