# SOSOKING FLIX 전환
기존 소스와 데이터는 archive/pre-flix-2026-11-26 및 Git 기록에 보존. 배포 산출물에는 플릭스만 포함. Firestore 규칙/데이터 변경 없음. 브랜드: 소소킹 AI영상 플레이어.
재생 클릭 즉시 브라우저 전체화면 요청, 지원 기기 가로 잠금 시도; 미지원 시 화면 채우기 및 회전 안내. 20초 전 다음 화 안내는 공식 플레이어 외부에 표시. 브라우저 자체 전체화면 및 자동재생 제한은 우회하지 않음. 테스트는 모의 플레이어이며 실기기/원본 재생은 별도 확인 필요.
공개 검색으로 확인한 원본 통합 영상과 8개 챕터. 원본 외부 재생 허용과 실제 작동은 미검증. 검색 결과 기반 수집 후보 스크립트는 YOUTUBE_API_KEY 환경변수 필요. 정기 수집 및 관리자 승인 UI는 아직 미구현. API 키는 코드/채팅에 공개하지 않음.
